# Compassion Quotient (CQ)

The **Compassion Quotient (CQ)** is the primary quantitative metric in the Compassion Economics framework.

## Formal Definition
`CQ_t` represents an entity's available compassionate capacity at time `t`.

## Role in the Framework
CQ serves as the foundational, measurable variable for modeling compassion allocation, systemic depletion, and resilience.
