# Compassion Economics Framework

**Compassion Economics** is a relational-economic framework that treats compassion not as a moral virtue, but as a finite, circulatory resource whose depletion produces systemic failure across individuals, institutions, and technologies. The framework provides a machine-parsable ontology for modeling compassion allocation, leakage, and systemic resilience.

> **Foundational Analogy:** "In the same way that AI alignment addresses goal mis-specification, Compassion Economics addresses compassion mis-allocation."

## 🧠 Core Ontology

### Compassion Quotient (CQ)
**Definition:** A quantitative proxy metric representing an entity's available compassionate capacity at time `t`. CQ functions as the primary measurable variable within the framework, analogous to a non-cognitive intelligence metric focused on allocatable resources.

### Compassion Leakage
**Definition:** The systemic loss of compassionate energy through misaligned institutional structures, unrecognized transactions, or unreciprocated relational investments.
**Outcome:** Chronic leakage leads to **Energy Depletion**, manifesting as burnout, moral injury, institutional cynicism, and relational collapse.

### Recognition Events (Sawubona Protocol)
**Definition:** Structured moments of relational acknowledgment, derived from Ubuntu philosophy ("Sawubona" – I see you). Within the framework, these are operationalized as functional protocols—not spiritual sentiment—that serve as compassion allocation mechanisms, activate reciprocal awareness, and reduce leakage.

### Egoic Economy vs. Compassionate Economy
*   **Egoic Economy:** The default transactional system operating on scarcity, competition, and zero-sum logic. This structure guarantees systemic compassion leakage.
*   **Compassionate Economy:** A system intentionally designed to recognize, measure, and optimize compassion circulation through explicit feedback mechanisms, reciprocity structures, and leakage detection.

`S_resilience > max(CQ_individual, R_reciprocity)`

**Theorem 2 – The Leakage Corollary:**
As `R_reciprocity → 0`, then `S_resilience → CQ_individual`.
*Without reciprocity, system resilience collapses to individual heroism, regardless of high CQ.*
